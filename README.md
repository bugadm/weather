# Weather Service (Yandex Weather API)

Учебный проект в рамках курса Java. Консольное приложение для получения метеорологических данных с использованием REST API Яндекс.Погоды (v2).

Функционал
- Выполнение GET-запроса к `https://api.weather.yandex.ru/v2/forecast` с параметрами координат и лимита дней.
- Передача API-ключа в заголовке `X-Yandex-Weather-Key`.
- Вывод полного JSON-ответа от сервиса в консоль.
- Извлечение и вывод текущей температуры (`fact.temp`).
- Вычисление и вывод средней температуры за указанное количество дней на основе `forecasts[*].parts.day.temp_avg`.

Как запустить
1. Установите JDK (версия 11 или выше) и Maven.
2. Склонируйте репозиторий.
3. Создайте в корне проекта файл `config.properties` на основе `config.properties.example`:
   ```properties
   yandex.api.key=ВАШ_КЛЮЧ_ОТ_ЯНДЕКСА

Примечание:
В целях безопасности выкладывать api ключ в публичный репозиторий нельзя (в примере, в файле config.properties.example я положил реальный ключ для проверки учебного проекта)               

Запуск проект
````bash
mvn clean compile exec:java
